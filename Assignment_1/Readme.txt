This CLI calculator will let you perform basic arithmetic operations (+, -, *, /) on 2 numbers only.
It has no memory and you cannot use your old value for a new operation.

It asks for you to input a number
Then validates the input
Then asks for a second number
Then validates again.

It then asks which operation you want to perform. You can select
1. Addition
2. Subtraction
3. Multiplication
4. Division

by typing in the number coresponding to the operation in the command line and hitting enter.
It will validate your entry and ask to reenter a number if you chose a number not 1-4.

It will perform the operation, display the result, and ask if you want to continue.
